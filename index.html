Saved Data

Aapka purana saara data (customers, entries, payments, history) alag jagah save hai aur settings se kabhi nahi badalta.

Cloud Sync

Do phones par ek hi data chalane ke liye. Customers, entries aur payments sync hote hain. Bill images (History) aur reminders sync nahi hote.

Sync band hai.

Setup (ek baar): console.firebase.google.com par project banao, phir Realtime Database → Create (test mode). Rules tab mein neeche wala text paste karke Publish karo. Phir Database URL yahan daalo.

Shop code hi aapke data ki chaabi hai, kisi ko mat batana.
